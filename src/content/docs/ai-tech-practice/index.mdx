## 怎么使用这 51 篇

这里保留全部 51 个英文选题，便于回到原始技术语境；每篇正文都是中文原创实践解读，不是全文翻译。页面会区分厂商或作者报告、站内已经可以检查的机制，以及尚待执行的低成本实验。

建议阅读顺序是：**context → harness → eval → security → model / inference → multimodal / science**。如果正文出现“我的实践”，它只能引用本站现有页面、规则、测试、代码或发布记录等可检查机制；没有站内证据的操作一律写成待执行实验，不能当成已经完成。

- [Managed Agents Runtime](/ai-tech-practice/managed-agents-runtime/)：练习把 Agent、工具、状态和审计记录放进一个受控运行时模型。
- [Dynamic Context Discovery](/ai-tech-practice/dynamic-context-discovery/)：练习让 Agent 先发现入口指针，再只加载当前任务需要的资料。
- [Scaling Autonomous Coding](/ai-tech-practice/scaling-autonomous-coding/)：练习用任务切片和独立验证扩大吞吐，而不是单纯增加 Agent 数量。

- [Codex Agent Loop](/ai-tech-practice/codex-agent-loop/)：练习实现只读工具循环，观察工具输出和压缩如何消耗上下文。
- [Parallel Claude C Compiler](/ai-tech-practice/parallel-claude-c-compiler/)：练习用参考实现、交叉测试和 delta debugging 约束并行开发。
- [Multi-agent Research System](/ai-tech-practice/multi-agent-research-system/)：练习在相同总预算下比较单 Agent 与并行研究的覆盖、重复和成本。
- [Effective Agent Tools](/ai-tech-practice/effective-agent-tools/)：练习比较 API 搬运型工具与面向任务的工具契约。
- [Cursor Harness for Codex Models](/ai-tech-practice/cursor-codex-model-harness/)：练习一次只改变一个模型特定 harness 变量并做窄 A/B。

- [AI-resistant Evaluations](/ai-tech-practice/ai-resistant-evaluations/)：练习在模型能力上涨后重新寻找仍能区分真实能力的评测信号。
- [Double-blind AI Evals](/ai-tech-practice/double-blind-ai-evals/)：练习用哈希、密封运行和 receipt 隔离模型与保密评测集。
- [AI Control Roadmap](/ai-tech-practice/ai-control-roadmap/)：练习用覆盖率、召回率和响应时间衡量 Agent 监督系统。
- [Gaia2 Agent Evaluation](/ai-tech-practice/gaia2-agent-evaluation/)：练习在模拟环境加入歧义、超时和状态变化，检查 Agent 恢复能力。
